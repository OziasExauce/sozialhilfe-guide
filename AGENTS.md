# Project rules

- Keep the deliverable as plain static HTML, CSS, and JavaScript with no framework, dependency, or build step, because it must deploy directly to GitHub Pages.
- Keep all user-facing copy in German and French on every page, because language switching is performed locally in the browser.
- Serve the preview as a direct redirect to `public/site/index.html`, never through an iframe, so styling and assets remain stable.
- Edit only the root deliverable files; `public/site/` is generated by `scripts/sync-preview.mjs` (run by a Vite plugin) with absolute `/site/` paths and content-hash cache-busting, because hand-copied relative paths broke the hosted preview.
- Resolve root-page assets through `/site/` only on Lovable-hosted domains using a conditional `<base>`, while preserving relative paths for GitHub Pages.
